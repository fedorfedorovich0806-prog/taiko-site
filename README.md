# TaikoVPN

Статический русскоязычный сайт: `index.html` — главная, `connect.html` — импорт подписки в Happ. Общие стили — `styles.css`, выбор платформ и приглашения — `site.js`, обработка подписок — `connect.js`. Локальный фирменный `logo.png`; внешних шрифтов, аналитики и зависимостей нет.

## Публикация

В GitHub Pages выберите публикацию из корня нужной ветки. Сохраните существующие `CNAME` и `.nojekyll`; настройте DNS домена из `CNAME` на GitHub Pages и включите HTTPS. Для обновления достаточно опубликовать файлы репозитория. Сборка не требуется. Перед публикацией проверьте реальные условия, оплату и доступность VPN в боте `@taikovpnbot`: сайт сам VPN не предоставляет.

## Ссылки и проверка

- `/?invite=123` перенаправляет в `https://t.me/taikovpnbot?start=ref_123`; принимаются только 1–20 цифр.
- `/connect.html#<URL>` принимает обычный или целиком percent-encoded HTTP(S) URL, открывает `happ://add/<URL>` и предлагает копирование. Ссылка находится во фрагменте и не отправляется серверу сайта; страница не запрашивает подписку. Не публикуйте настоящие токены в тестах и скриншотах.
- Пустой, повреждённый и неподдерживаемый адрес не импортируется. `example.com` и поддомены явно отмечены как демо, импорт отключён.
- Вручную проверьте обе страницы на телефоне и компьютере, выбор четырёх платформ, FAQ, навигацию клавиатурой и режим уменьшенного движения. Открытие Happ требует установленного приложения и разрешения браузера; успешное открытие не означает активную VPN-подписку.

Для локального просмотра: статический HTTP-сервер из корня репозитория (например, `python -m http.server 8080`). Для синтаксиса JS: `node --check site.js` и `node --check connect.js`. Регрессионные проверки без зависимостей: `node --test site.test.cjs` (приглашения, кодирование URL, ошибки, демо, копирование и смена фрагмента).
